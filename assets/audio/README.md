# Audio assets for Muse ML Feedback

Place your audio files here:

| File | Required | Description |
|------|----------|-------------|
| `calibration.opus` | Yes | 60-second calibration tone |
| `harmonic_consonance.opus` | Yes | Feedback loop sound (placeholder until generative audio) |
| `end_chime.opus` | Yes | Bowl chime played at session end |

Supported formats: opus (preferred), mp3, wav, ogg, aac, flac, wma

Opus has no startup delay on Android with just_audio.
