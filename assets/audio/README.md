> if distributing.

Supported formats: opus (Ogg Opus), ogg (vorbis/flac), mp3, wav, flac —
flutter_soloud 4.x bundles the Xiph decoders (`libopus`/`libogg`/`libvorbis`)
and decodes Opus natively on Android and Linux.
